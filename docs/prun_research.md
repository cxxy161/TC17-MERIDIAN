# Prosperous Universe (PrUn) 玩法设计与经济系统深度调研报告

> 调研来源：[Prosperous Universe 官方博客](https://prosperousuniverse.com/blog)（含 Devlogs、Gateway / Orchestration 等版本更新）及当前线上版本机制。

---

## 一、 游戏定位与核心循环

* **硬核实时异步经济沙盒**：无战斗、无传统经验值/等级体系，核心是经营一家太空商业公司。时间以**现实世界小时**推进，生产、航行与市场挂单在离线时持续运行。
* **APEX 终端界面**：全浏览器端可高度自定义的“电子表格 + 命令行”式操作台（如 `PLI` 行星信息、`CX` 交易所、`FLY` 飞行控制、`RTE` 航线编辑、`INFL` 通胀指数、`POPR` 人口报告、`POPI` 人口基建、`BLU` 蓝图、`SHY` 造船厂等）。
* **核心闭环**：
  `资源勘探/开采` → `多级工业精炼与制造` → `星际物流与航运` → `交易所/本地市场交易` → `劳动力消耗与行星基建维护`

## 二、 经济与金融系统

### 1. 全玩家驱动市场与多币种经济区
* **几乎“零 NPC 魔法”**：绝大部分商品、飞船、建材、燃料和消耗品均由玩家生产、运输和定价。仅在极少数封闭区间或基础兜底商品上存在系统做市商。
* **四大阵营经济区与法定货币**：
  * **AIC**（Antares Initiative，火星系）
  * **CIS**（Castillo-Ito Mercantile，科技与自动化导向）
  * **NCC**（NEO Charter Exploration，以 Moria/Montem 为核心）
  * **ICA**（Insitor Cooperative，农业与资源导向）
* **外汇市场（FX）与空间套利**：同一商品在不同阵营交易所（CX）的价格差异驱动长途贸易与汇率波动。

### 2. 双层市场结构与合约系统
* **商品交易所（CX）**：标准的中央限价订单簿（CLOB），支持限价单（Limit）与市价单（Market），按价格优先、时间优先撮合。
* **本地市场（Local Market, LM）**：行星级点对点市场，支持收购/出售广告及**私人运输/供应合约（Contracts）**。广告挂单费与合约税率由基础常数与挂单时长乘数决定，结算币种绑定该行星当前 CoGC 总督所属阵营。

### 3. 货币水龙头（Faucets）与蓄水池（Sinks）
由于 PrUn 没有传统 MMO 的“战斗炸船毁灭物品”机制，其经济平衡完全依赖货币与物资的结构性循环：

| 机制分类 | 具体来源 / 去向 | 说明 |
| :--- | :--- | :--- |
| **水龙头 (Faucets)** | **做市商收购 (MM Buys)** | 系统做市商收购特定基础原料或封闭区间商品，直接生成新货币 |
| | **阵营合约 (Faction Contracts)** | 完成系统发布的周期性/新手合约获得直接信用点奖励 |
| | **新公司启动资金** | 新注册玩家获得的初始资本（每周随 `INFL` 自动微调） |
| **蓄水池 (Sinks)** | **行星基建与行政税费 (`POPI`/`CoGC`)** | 公共设施维护、总督竞选/治理税费、LM 挂单广告费与交易税 |
| | **做市商卖出 (MM Sells)** | 玩家向系统做市商购买特定商品时，货币从流通中销毁 |
| | **建筑/飞船维修与折旧** | 建筑老化维修、飞船燃料与部件损耗形成持续的物资黑洞 |
| | **不活跃账号沉淀** | 退游玩家账户内的资金永久退出活跃流通 |

### 4. 通胀追踪（`INFL`）与动态做市商（DMM）
* **结构性通胀痛点**：早期静态高价 MM 收购导致水龙头长期大于蓄水池，引发严重通胀与“MM 印钞机漏洞”。
* **`INFL` 通胀指数**：以选定时间窗口（日/月/年）起点为 **100% 基准线**，绘制累计通胀曲线与周期环比柱状图；支持按单一货币、全宇宙商品或自定义商品篮子（如“劳动力消耗品篮子”、“建筑预制件篮子”）独立核算。
* **动态做市商（DMM）**：取代静态做市商，针对封闭区间商品，依据**过去 10 天的市场成交均价与波动趋势**自动浮动调整 MM 报价，防止无风险套利。新公司启动资金与阵营合约奖励也每周与 `INFL` 均值挂钩自动缩放。

## 三、 生产、劳动力与人口基础设施

### 1. 生产效率公式
$$\text{总效率} = f(\text{建筑完好度}, \text{劳动力可用率}, \text{消耗品满足度}) + \text{专家加成} + \text{CoGC/土壤加成}$$
* **建筑完好度（Condition & Repair）**：新建建筑为 100%，随运行时间持续老化，最低跌至 **33% 效率下限**。玩家需投入对应维修材料恢复完好度。
* **劳动力可用率**：若基地住房容量（Habitation）低于产线需求，或行星总人口不足，效率按比例折减。

### 2. 行星人口与公共基建（`POPR` & `POPI`）
* **7 天全局结算周期（`POPR`）**：行星人口为全星球共享的动态池，每 7 天结算一次人口增长、迁移与劳动力重分配。
* **四维需求金字塔与木桶效应**：
  * 需求层级：**生命支持（Life Support）→ 安全与健康（Safety & Health）→ 舒适与文化（Comfort & Culture）→ 教育（Education）**。
  * **木桶效应**：高阶需求的满足度不能超过低阶需求（如安全仅 60%，则舒适最高仅生效 60%）。
  * **公共基建（`POPI`）**：由全星球玩家共同出资建设并维护，分为**每日快速消耗**与**每周慢速消耗**两种物料维护周期。
* **幸福度与失业率**：幸福度由四维需求满足度、失业率及上一周期历史幸福度共同决定。失业率过高惩罚幸福度并导致人口萎缩；失业率过低（接近 0%）带来“就业机会”加成但会导致部分基地招工不足。
* **存量保护机制**：每周 `POPR` 重分配劳动力时，老基地可保留现有劳动力的较大比例（最高达 **75%**），防止新基地恶意“吸干”老玩家工人。

## 四、 产线设计与核心数值

### 1. 硬性空间约束：500 面积单位（Area Limit）
* 每个行星基地初始上限严格锁定为 **500 area units**。
* 采矿机、工厂、仓库（`WAR`）、住房（Habitation）全部占用面积。
* **设计意图**：500 面积无法塞下全产业链，**强制玩家进行基地专业化**（如采矿星、冶炼星、农业星分工），从而创造出刚性的跨星际运输需求。

### 2. 五级劳动力与精确消耗数值
* **五级劳动力**：**Pioneers (PIE) → Settlers (SET) → Technicians (TEC) → Engineers (ENG) → Scientists (SCI)**。
* 每栋生产建筑有精确的定员需求（例如：1 座基础材料厂 BMP 需 **100 名 Pioneers**）。
* **消耗品双轨制（以 100 名 Pioneers 每日消耗为例）**：
  * **必需品（Essential，断供即停工）**：
    * 饮用水（`DW`）：**4 单位 / 天**
    * 口粮（`RAT`）：**4 单位 / 天**
    * 基础工装（`OVE`）：**0.5 单位 / 天**
  * **奢侈品（Luxury，可选，用于提升满意度与产能速度）**：
    * 咖啡因饮品（`COF`）：**0.5 单位 / 天**
    * 加厚工装（`PWO`）：**0.2 单位 / 天**

### 3. 产业链分层结构
* **T1 原料开采**：Rigs / Mines / Collectors 直接从行星提取（受星球资源丰度与重力/大气影响）。
* **T2 基础加工**：如 BMP（基础材料厂，碳+氢 → 聚乙烯）、冶炼厂（矿石 → 生铁/钢）。
* **T3 进阶组件与消耗品**：机械零件、电子元件、高阶食物/医疗品（需 SET/TEC）。
* **T4 高精尖与大型基建**：飞船引擎、反应堆、FTL 控制器、建筑预制件（Prefabs）、星门组件（需 ENG/SCI，耗时数天至数周）。

## 五、 物流、造船与星门系统

1. **飞船蓝图与造船厂（`BLU` / `SHY`）**
   * 在 `BLU` 中平衡货舱体积（$\text{m}^3$）、载重（$\text{t}$）、STL/FTL 引擎、燃料舱与反应堆。
   * 蓝图在行星造船厂（`SHY`）立项即永久锁定，填入全部物料后耗时数天完成建造；支持基于原蓝图与目标蓝图的差价改装。
2. **航程拆解与物理规律（`FLY` / `RTE`）**
   $$\text{总航行时间} = \text{离港加速} + \text{STL 航段} + \text{FTL 跳跃} + \text{进港减速} + \text{起飞/降落固定耗时}$$
   * **STL（亚光速）**：消耗标准燃料（SF），总质量 = 空船质量（OEM）+ 货物重量 + 燃料质量。STL 功率与燃料滑块大致呈线性关系（燃料翻倍 ≈ 时间减半）。脱离高重力行星（如 Montem）需最低推力阈值，否则离港时间指数级暴增。
   * **FTL（超光速）**：消耗聚变燃料（FF），基础耗量约 **7.2 FF / 秒差距**（@ 100% 功率）。具有**严重边际递减**：功率从 25% 翻倍到 50%，燃料消耗翻倍但时间仅缩短约 **8%**，因此玩家普遍锁定最低档。
   * **自动航线（`RTE`）**：支持设定多航点自动往返、自动加油与装卸货物。
3. **星门系统（Gateways，2025年11月上线）**
   * 跨星系大型基建，消耗 **Vortex Fuel（涡旋燃料）**，通过星门寻址与路径规划将孤立星系直连，重塑全宇宙的物流拓扑与套利半径。

## 六、 政治治理与公司合作

* **行星议会与总督选举（CoGC - Chamber of Global Commerce）**：玩家竞选行星总督。当选总督决定该行星使用的**阵营货币与市场税率**，其推行的政策为特定类型建筑（如采矿、制造、农业）提供**全行星范围的产能加成**。
* **公司与联盟（Corporations）**：多个玩家公司可组建 Corporation，共享仓库、发行股份、建设公司总部（Corporate HQ，提供行星产能加成）并协作推进大型基建或星门项目。

## 七、 对当前项目（`Meridian`）的设计启发

1. **货币与通胀锚定**：多货币 + CLOB 交易所 + 类似 `INFL` 的一篮子商品通胀指数，用于动态调节系统级奖励或做市商报价，防止早期/后期货币体系崩溃。
2. **消耗品驱动的刚性需求**：通过多级劳动力消耗品与行星公共基建（`POPI`）消耗，为高阶工业品制造持续的“消耗黑洞（Sink）”，避免市场长期过剩。
3. **空间与物理约束**：用基地面积上限（500 units）、货舱体积/重量双限制、燃料消耗与现实时间航行，自然拉开不同星系/行星之间的价差，让“纯物流/贸易商”成为独立且可盈利的职业路径。
